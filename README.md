# Container Door State Detection

This project uses a YOLOv8 model and custom image processing logic to detect whether a container door is **Open** or **Closed** in a video.

## Files

- `door_state_detection.py` – Main script to run detection and tracking
- `requirements.txt` – Python dependencies

## How to Run

1. Install requirements:

   ```bash
   pip install -r requirements.txt
